# RFC 3161 External Timestamping Authority (TSA)

> **Enterprise Pillar 1 & 4 — Non-repudiation & Legal Auditability**

## Overview

ProofPay integrates **RFC 3161 trusted timestamping** for all terminal milestone settlements,
Merkle transparency tree checkpoints, and dispute dossier filings.

While Ed25519 signatures authenticate **who** signed a verdict, RFC 3161 cryptographic
tokens prove **when** the decision existed with proof backed by an independent third-party
public Time Stamping Authority (TSA), eliminating server clock spoofing and backdating.

## Supported Protocols

- **Standard**: RFC 3161 / RFC 5816
- **Hash Algorithm**: SHA-256 (`2.16.840.1.101.3.4.2.1`)
- **Default Authority**: FreeTSA / DigiCert / GlobalSign TSA compatible

## Usage

```typescript
import { requestTimestampToken, verifyTimestampToken } from '@/lib/crypto/rfc3161'

// 1. Generate proof-of-existence token for a milestone decision
const token = await requestTimestampToken({
  hash: decisionPayloadHash,
})

// 2. Verify token
const isValid = verifyTimestampToken(token, decisionPayloadHash)
```
